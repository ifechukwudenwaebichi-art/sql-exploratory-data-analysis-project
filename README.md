
# sql-data-analytics-project

Hi, welcome to my sql-exploratory-data-analysis- project.

This is a comprehensive collection of SQL scripts for data exploration, analytics, and reporting. These scripts cover various analyses, including database exploration, measures and metrics, time-based trends, cumulative analytics, segmentation, and more.

This repository contains SQL queries designed to help data analysts and BI professionals explore, segment, and analyze data within relational databases. Each script focuses on a specific analytical area and demonstrates practical SQL techniques and best practices.
